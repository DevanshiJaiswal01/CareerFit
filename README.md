

# CareerFit – Skill and Career Recommendation System

## About the Project
CareerFit is a web-based application designed to help students identify suitable career options based on their technical skills, interests and educational background.

## Objectives
- Assess students' technical and soft skills.
- Identify students' career interests.
- Analyze skill levels and interests.
- Recommend suitable career paths.

## Main Features
1. Student Registration and Login
2. Student Profile Management
3. Skill Assessment
4. Interest Selection
5. Career Recommendation
6. Strong and Weak Skill Identification

## Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- C#
- ASP.NET Core

**Database**
- SQLite

## Career Recommendations
CareerFit provides career suggestions such as:
- Web Developer
- Data Analyst
- AI/ML Engineer

Recommendations are generated using the student's saved skill ratings and selected interests.

## Project Purpose
The main purpose of CareerFit is to guide students in understanding their strengths and exploring suitable career opportunities.
