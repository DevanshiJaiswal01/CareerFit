
# CareerFit - Project Features

## 1. Student Registration
Allows new students to create an account by providing their name, email and password.

## 2. Student Login
Allows registered students to securely access their accounts.

## 3. Student Dashboard
Provides a central place to access the main modules of CareerFit.

## 4. Profile Management
Allows students to view and update their personal and educational details.

## 5. Skill Assessment
Allows students to rate their technical and soft skills on a five-level scale:
- Beginner
- Basic
- Intermediate
- Advanced
- Expert

Skills include Python, C#, SQL, HTML/CSS, JavaScript, Communication and Problem Solving.

## 6. Interest Selection
Allows students to select and update their preferred career fields.

## 7. Career Recommendation
Generates suitable career suggestions using the student's saved skill ratings and selected interests.

## 8. Strong and Weak Skill Identification
Displays students' stronger skills and areas that may need improvement.

## 9. Database Management
Uses SQLite to store student accounts, profile information, skill ratings and interests.
