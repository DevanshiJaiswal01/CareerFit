
# CareerFit - Project Setup Guide

## 1. Project Overview
CareerFit is a web-based Skill and Career Recommendation System designed to help students explore suitable career paths.

## 2. Technologies Used
- HTML
- CSS
- JavaScript
- C#
- ASP.NET Core
- SQLite

## 3. Project Modules
- Student Registration
- Student Login
- Student Profile Management
- Skill Assessment
- Interest Selection
- Career Recommendation

## 4. Backend Setup
1. Open the CareerFitAPI project folder.
2. Open the terminal in that folder.
3. Restore the project packages.
4. Build the ASP.NET Core application.
5. Start the backend server.

## 5. Frontend Setup
1. Open the frontend folder in Visual Studio Code.
2. Open the home page.
3. Run the frontend using the Live Server extension.
4. Register or log in to access the dashboard.

## 6. Database
CareerFit uses SQLite to store student accounts, skill assessments, interests and profile information.

## 7. Project Output
The system provides career recommendations based on students' saved skills and selected interests.
