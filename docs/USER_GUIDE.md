
# CareerFit - User Guide

## 1. Introduction
CareerFit is a Skill and Career Recommendation System that helps students explore suitable career opportunities.

## 2. Getting Started
Open the CareerFit home page and select Get Started to access the application.

## 3. Student Registration
New students can create an account by entering their name, email address and password.

## 4. Student Login
Registered students can log in using their email and password.

## 5. Dashboard
The dashboard provides access to the main application modules.

## 6. Profile Management
Students can enter and update their educational and personal information.

## 7. Skill Assessment
Students can rate their technical and soft skills using the available rating options.

## 8. Interest Selection
Students can select their preferred career fields from the available interest categories.

## 9. Career Recommendation
The system analyzes saved skill ratings and selected interests to display suitable career options.

## 10. Viewing Results
Students can review their career matches, strong skills and areas requiring improvement.

## 11. Conclusion
CareerFit provides students with a simple platform to understand their skills and explore possible career paths.
