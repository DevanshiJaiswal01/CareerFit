
# CareerFit - Technology Stack

## 1. Frontend Technologies

### HTML
HTML is used to create the structure of CareerFit web pages, including registration, login, dashboard, skill assessment and career recommendation pages.

### CSS
CSS is used to design the website layout, colours, buttons, cards and overall user interface.

### JavaScript
JavaScript handles frontend interactions, form validation, API communication and displaying career recommendation results.

## 2. Backend Technology

### C#
C# is used to implement the application logic and handle student data processing.

### ASP.NET Core
ASP.NET Core provides the backend APIs for registration, login, profile management, skill assessment, interest selection and career recommendations.

## 3. Database Technology

### SQLite
SQLite is used to store student account details, profile information, skill ratings and selected interests.

## 4. Development Tools

- Visual Studio Code: Source code editing.
- .NET CLI: Building and running the ASP.NET Core application.
- GitHub: Source code hosting and version control.

## 5. Technology Integration

The frontend communicates with the ASP.NET Core backend through HTTP requests. The backend processes the requests and interacts with the SQLite database to store and retrieve student information.
